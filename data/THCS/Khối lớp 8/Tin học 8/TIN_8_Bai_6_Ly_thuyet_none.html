Bài 6: Thực hành lập trình với Python

Tin học 8 • Chủ đề 6: Thực hành lập trình với Python

1. Cài đặt Python

Để lập trình Python trên máy tính, em cần cài đặt Python từ trang chủ python.org. Khi cài đặt trên Windows, nhớ đánh dấu chọn ô "Add python.exe to PATH" để có thể gọi Python từ mọi nơi.

Sau khi cài đặt, em có thể viết chương trình bằng phần mềm IDLE đi kèm Python, hoặc các phần mềm khác như Visual Studio Code. Tệp chương trình Python có phần mở rộng là .py.

Ghi nhớ: Tệp chương trình Python có phần mở rộng là .py.

2. Lệnh print - đưa dữ liệu ra màn hình

Lệnh print() dùng để in dữ liệu ra màn hình. Văn bản cần đặt trong cặp dấu nháy đơn hoặc nháy kép.

print("Xin chào các bạn!")
print('Chào mừng đến với Python')
print(2026)

Lệnh print() có thể in nhiều giá trị cách nhau bởi dấu phẩy:

print("Năm nay là năm", 2026)

Kết quả trên màn hình: Năm nay là năm 2026

3. Lệnh input - nhập dữ liệu từ bàn phím

Lệnh input() dùng để nhập dữ liệu từ bàn phím khi chương trình đang chạy.

ten = input("Nhập tên của bạn: ")
print("Chào bạn", ten)

Lưu ý quan trọng: kết quả của input() luôn là chuỗi ký tự. Nếu muốn tính toán với số, phải chuyển sang số nguyên bằng lệnh int():

tuoi = int(input("Nhập tuổi của bạn: "))
print("Năm sau bạn", tuoi + 1, "tuổi")
Ghi nhớ: input() trả về chuỗi ký tự. Muốn tính toán với số nguyên, phải dùng int() để chuyển đổi.

4. Câu lệnh rẽ nhánh if

Câu lệnh if cho phép chương trình thực hiện công việc khác nhau tùy điều kiện đúng hay sai. Cú pháp:

if điều_kiện:
    các lệnh thực hiện khi điều kiện đúng
else:
    các lệnh thực hiện khi điều kiện sai

Lưu ý: sau điều kiện có dấu hai chấm, và các lệnh bên trong phải thụt đầu dòng so với if.

Ví dụ kiểm tra điểm 10:

diem = int(input("Nhập điểm: "))
if diem == 10:
    print("Điểm tuyệt đối! Thật xuất sắc!")
else:
    print("Cố gắng hơn ở lần sau nhé!")

Các phép so sánh trong Python: bằng (hai dấu bằng), khác nhau, lớn hơn, nhỏ hơn, lớn hơn hoặc bằng, nhỏ hơn hoặc bằng.

5. Vòng lặp for với range()

Vòng lặp for dùng để lặp lại công việc với số lần biết trước. Hàm range() tạo ra một dãy số:

Cách viếtDãy số tạo ra
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(1, 10, 2)1, 3, 5, 7, 9

Ví dụ in ra 5 dòng chào:

for i in range(5):
    print("Chào lần thứ", i + 1)
Ghi nhớ: range(n) tạo dãy số từ 0 đến n trừ 1. Câu lệnh for cũng cần dấu hai chấm và thụt đầu dòng cho các lệnh bên trong.
