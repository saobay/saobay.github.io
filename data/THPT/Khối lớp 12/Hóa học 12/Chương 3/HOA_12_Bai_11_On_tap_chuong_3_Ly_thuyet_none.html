Chương 3: Hợp chất chứa nitrogen — Hóa học 12 (Kết nối tri thức với cuộc sống)

1. Hệ thống kiến thức chương 3

Chương 3 nghiên cứu các hợp chất hữu cơ chứa nitrogen: amine, amino acid, peptide, protein và enzyme.

Nội dung Amine Amino acid Peptide / Protein
Khái niệm Dẫn xuất của $\mathrm{NH_3}$ (thay H bằng gốc hydrocarbon) Chứa $-\mathrm{NH_2}$ và $-COOH$ Chuỗi các gốc amino acid nối bằng liên kết peptide
Đại diện $\mathrm{CH_3NH_2}$, $\mathrm{C_6H_5NH_2}$ Gly ($M=75$), Ala ($M=89$) Gly-Gly ($M=132$), albumin, insulin
Tính chất đặc trưng Tính base; aniline + bromine → kết tủa trắng Tính lưỡng tính; ion lưỡng cực Thủy phân → amino acid; protein + $\mathrm{Cu(OH)_2}$/kiềm → màu tím
Ứng dụng Dược phẩm, phẩm nhuộm Bột ngọt, thuốc bổ Thực phẩm, enzyme công nghiệp

2. So sánh tính base

Thứ tự tính base giảm dần: alkyl amine (bậc 2 $\gt$ bậc 1) $\gt$ $\mathrm{NH_3}$ $\gt$ aniline.

  • Gốc alkyl đẩy electron → tăng mật độ electron trên N → tính base tăng.
  • Gốc phenyl hút electron → giảm mật độ electron trên N → tính base giảm.

📌 Ghi nhớ

Dãy so sánh tính base thường gặp: $\mathrm{(CH_3)_2NH \gt CH_3NH_2 \gt NH_3 \gt C_6H_5NH_2}$.

3. Các phản ứng nhận biết quan trọng

  • Aniline: nước bromine → kết tủa trắng 2,4,6-tribromoaniline.
  • Protein: $\mathrm{Cu(OH)_2}$/kiềm → màu tím (phản ứng biuret).
  • Amine (alkyl): làm quỳ tím chuyển xanh.

4. Bài tập mẫu

Ví dụ 1 — Hỗn hợp amine + amino acid:

Cho $16,8$ gam hỗn hợp gồm aniline ($M = 93$) và glycine ($M = 75$) tác dụng với HCl dư thu được $23,05$ gam muối. Tính phần trăm khối lượng của aniline.

Lời giải: Đặt $n_{aniline} = a$, $n_{glycine} = b$:

$93a + 75b = 16,8$; $129,5a + 111,5b = 23,05$ → $a = b = 0,1$.

$m_{aniline} = 9,3$ gam → $\% = 9,3/16,8 \times 100\% = 55,4\%$.

Ví dụ 2 — Đốt cháy amino acid:

Đốt cháy hoàn toàn $8,9$ gam alanine ($\mathrm{C_3H_7NO_2}$). Tính thể tích $\mathrm{CO_2}$ (đktc).

Lời giải: $n_{alanine} = 0,1$ mol → $n_{\mathrm{CO_2}} = 0,3$ mol → $V = 6,72$ lít.

Tóm tắt chương 3

  • Amine: tính base; $\mathrm{(CH_3)_2NH \gt CH_3NH_2 \gt NH_3 \gt C_6H_5NH_2}$; aniline + bromine → kết tủa trắng.
  • Amino acid: lưỡng tính; trùng ngưng → peptide (tách nước).
  • Peptide/Protein: liên kết $-CO-NH-$; thủy phân (cộng nước) → amino acid; protein cho màu tím biuret; đông tụ khi đun nóng.
  • Enzyme: protein xúc tác; mạnh – đặc hiệu – điều kiện nhẹ; dễ biến tính.
