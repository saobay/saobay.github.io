Bài 24: Xây dựng phần đầu trang web

Định hướng Tin học ứng dụng — Kết nối tri thức với cuộc sống

1. Cấu trúc phần đầu trang

Phần đầu trang (header) gồm: logo/tên web, tiêu đề, đôi khi có biểu ngữ (banner). Viết bằng HTML, định dạng bằng CSS.

<header>
  <img src="images/logo.png" alt="Logo lớp 12A1">
  <h1>Lớp 12A1 – THPT Sào Báy</h1>
  <p>Học tập – Rèn luyện – Trưởng thành</p>
</header>

2. Định dạng bằng CSS

header {
  background-color: #1e3a8a;
  color: white;
  text-align: center;
  padding: 20px;
}
header img {
  width: 80px;
}
  • Nền (background-color): màu đặc trưng.
  • Chữ (color, text-align): tương phản, căn giữa.
  • Logo (width): kích thước vừa phải.
  • Đệm (padding): thoáng.

📌 Ghi nhớ

Đầu trang: logo + tên + khẩu hiệu. HTML cấu trúc, CSS định dạng: nền, chữ tương phản, căn giữa, logo vừa, padding thoáng.

Tóm tắt toàn bài

  • header: logo, tên web, khẩu hiệu/banner.
  • HTML: img (src, alt), h1, p.
  • CSS: background-color, color, text-align, padding, width.
