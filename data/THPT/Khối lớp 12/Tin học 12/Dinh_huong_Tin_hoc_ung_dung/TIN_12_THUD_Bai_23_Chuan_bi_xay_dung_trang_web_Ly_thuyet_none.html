Bài 23: Chuẩn bị xây dựng trang web

Định hướng Tin học ứng dụng — Kết nối tri thức với cuộc sống

1. Xác định yêu cầu website

  • Mục đích: giới thiệu lớp/trường, bán hàng, tin tức...
  • Đối tượng: học sinh, phụ huynh, khách hàng...
  • Nội dung: các trang cần có (trang chủ, giới thiệu, liên hệ...).

2. Phác thảo bố cục và chuẩn bị

  • Phác thảo: vẽ sơ đồ các khối (đầu trang, menu, nội dung, chân trang).
  • Công cụ: trình soạn thảo (Notepad++, VS Code), trình duyệt để xem thử.
  • Cấu trúc thư mục: thư mục chứa file HTML, thư mục con chứa ảnh (images), file CSS (style.css).
  • Thu thập nội dung: văn bản, ảnh (đúng bản quyền), logo.

📌 Ghi nhớ

Chuẩn bị: xác định yêu cầu (mục đích, đối tượng) → phác thảo bố cục → chuẩn bị công cụ, thư mục, nội dung (đúng bản quyền).

Tóm tắt toàn bài

  • Yêu cầu: mục đích, đối tượng, nội dung các trang.
  • Phác thảo: sơ đồ khối trước khi viết mã.
  • Chuẩn bị: trình soạn thảo, cấu trúc thư mục, nội dung đúng bản quyền.
