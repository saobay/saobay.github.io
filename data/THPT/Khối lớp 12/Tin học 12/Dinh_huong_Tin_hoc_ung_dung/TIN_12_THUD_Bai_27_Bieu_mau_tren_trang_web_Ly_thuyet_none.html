Bài 27: Biểu mẫu trên trang web

Định hướng Tin học ứng dụng — Kết nối tri thức với cuộc sống

1. Biểu mẫu (form)

Thẻ form tạo biểu mẫu thu thập thông tin: đăng ký, liên hệ, khảo sát.

<form>
  <label>Họ tên:</label>
  <input type="text" name="hoten">
  <label>Email:</label>
  <input type="email" name="email">
  <input type="submit" value="Gửi">
</form>

2. Các điều khiển

ThẻDùng cho
input type="text"Ô nhập một dòng (tên...)
input type="email"Ô nhập email (kiểm tra định dạng)
input type="password"Ô mật khẩu (hiện dấu chấm)
input type="radio"Chọn một trong nhiều
input type="checkbox"Chọn nhiều
selectDanh sách thả xuống
textareaÔ nhập nhiều dòng
input type="submit"Nút gửi
labelNhãn cho ô nhập

📌 Ghi nhớ

form thu thập thông tin. label + input (text, email, password, radio một lựa chọn, checkbox nhiều, submit). select: thả xuống; textarea: nhiều dòng.

Tóm tắt toàn bài

  • Biểu mẫu: thẻ form — đăng ký, liên hệ, khảo sát.
  • Điều khiển: label, input (text/email/password/radio/checkbox/submit), select, textarea.
  • Nguyên tắc: nhãn rõ, đúng loại ô, nút gửi rõ ràng.
