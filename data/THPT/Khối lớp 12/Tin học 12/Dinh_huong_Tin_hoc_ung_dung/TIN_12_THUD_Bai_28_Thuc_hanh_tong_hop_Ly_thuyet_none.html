Bài 28: Thực hành tổng hợp

Định hướng Tin học ứng dụng — Kết nối tri thức với cuộc sống

1. Mục tiêu

Vận dụng tổng hợp các bài 23–27 để xây dựng hoàn chỉnh một website: đầu trang, thân trang, chân trang, điều hướng, biểu mẫu.

2. Quy trình thực hiện

  1. Lập kế hoạch: chủ đề, các trang, phân công, tiến độ.
  2. Chuẩn bị: nội dung, ảnh, phác thảo bố cục.
  3. Xây dựng khung: header, nav, footer dùng chung.
  4. Xây dựng nội dung: main từng trang (section, article).
  5. Thêm tương tác: liên kết, biểu mẫu liên hệ/đăng ký.
  6. Định dạng CSS: nhất quán toàn web.
  7. Kiểm thử: liên kết, hiển thị, nhiều thiết bị.
  8. Trình bày: giới thiệu web trước lớp.

3. Tiêu chí đánh giá

  • Đầy đủ: đủ các phần, các trang theo kế hoạch.
  • Đúng kĩ thuật: HTML hợp lệ, CSS nhất quán, liên kết đúng.
  • Thẩm mĩ: đẹp, dễ đọc, dễ dùng.
  • Nội dung: đúng, mới, bản quyền.
  • Trình bày: rõ ràng, tự tin.

📌 Ghi nhớ

Tổng hợp: kế hoạch → khung chung → nội dung → tương tác → CSS → kiểm thử → trình bày. Đánh giá: đầy đủ, đúng kĩ thuật, thẩm mĩ, nội dung tốt, trình bày tốt.

Tóm tắt toàn bài

  • Mục tiêu: website hoàn chỉnh từ các kĩ năng đã học.
  • Quy trình 7 bước: kế hoạch → chuẩn bị → khung → nội dung → tương tác → CSS → kiểm thử → trình bày.
  • Tiêu chí: đầy đủ, đúng kĩ thuật, thẩm mĩ, nội dung, trình bày.
