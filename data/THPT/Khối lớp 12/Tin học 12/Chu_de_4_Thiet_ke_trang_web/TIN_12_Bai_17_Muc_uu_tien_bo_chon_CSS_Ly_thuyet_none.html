Bài 17: Các mức ưu tiên của bộ chọn

Chủ đề 4: Giải quyết vấn đề với sự trợ giúp của máy tính — Kết nối tri thức với cuộc sống

1. Các loại bộ chọn

Bộ chọnCú phápChọn phần tử
Tên thẻpMọi thẻ p
Lớp.noteMọi phần tử có class="note"
Định danh#mainPhần tử duy nhất có id="main"
Toàn cục*Mọi phần tử
Nhómh1, h2Cả thẻ h1 và h2
Con cháudiv pThẻ p nằm trong div (mọi cấp)
Con trực tiếpdiv > pThẻ p là con trực tiếp của div

Lưu ý: class dùng cho nhiều phần tử (có thể gán nhiều class cho một phần tử); id là duy nhất trong trang, thường dùng cho các khối chính.

2. Thứ tự ưu tiên

Khi nhiều quy tắc cùng định dạng một phần tử, quy tắc có độ ưu tiên cao hơn thắng. Thứ tự từ cao xuống thấp:

  1. !important — thắng tất cả (hạn chế dùng).
  2. Kiểu nội tuyến (inline style) — viết trong thuộc tính style của thẻ.
  3. Bộ chọn id (#main).
  4. Bộ chọn class (.note), bộ chọn thuộc tính, giả lớp.
  5. Bộ chọn tên thẻ (p), giả phần tử.
  6. Bộ chọn toàn cục (*) — thấp nhất.

Nếu cùng độ ưu tiên, quy tắc viết sau trong file CSS thắng. Quy tắc trong file CSS ngoài và thẻ style có độ ưu tiên như nhau — cũng xét theo thứ tự viết.

p { color: blue; }
.note { color: green; }
#main { color: red; }
/* Thẻ p có id="main" class="note": chữ ĐỎ (id thắng) */

3. Tính điểm ưu tiên (specificity)

Có thể tính "điểm" của bộ chọn theo bộ bốn số (nội tuyến, id, class, thẻ), so sánh từ trái sang phải:

Bộ chọnĐiểm (nội tuyến, id, class, thẻ)
p(0, 0, 0, 1)
.note(0, 0, 1, 0)
#main(0, 1, 0, 0)
#main .note p(0, 1, 1, 1)
Kiểu nội tuyến(1, 0, 0, 0)

Ví dụ: .a .b .c có điểm (0, 0, 3, 0) thua #main có điểm (0, 1, 0, 0) — vì so sánh từ trái sang: id (1 so với 0) quyết định trước, không cộng dồn kiểu "3 class bằng 1 id".

📌 Ghi nhớ

Ưu tiên: !important > nội tuyến > id > class > tên thẻ > *. Cùng ưu tiên → viết sau thắng. Điểm specificity: (nội tuyến, id, class, thẻ), so sánh từ trái sang phải — 1 id thắng mọi số class.

Tóm tắt toàn bài

  • Bộ chọn: tên thẻ, class (nhiều phần tử), id (duy nhất), *, nhóm, con cháu, con trực tiếp.
  • Thứ tự ưu tiên: !important > nội tuyến > id > class > tên thẻ > *; cùng ưu tiên thì viết sau thắng.
  • Specificity: bộ bốn (nội tuyến, id, class, thẻ), so sánh từ trái sang phải.
