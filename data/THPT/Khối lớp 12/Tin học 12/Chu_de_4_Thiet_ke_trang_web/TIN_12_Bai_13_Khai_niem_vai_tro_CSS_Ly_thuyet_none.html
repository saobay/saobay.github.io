Bài 13: Khái niệm, vai trò của CSS

Chủ đề 4: Giải quyết vấn đề với sự trợ giúp của máy tính — Kết nối tri thức với cuộc sống

1. CSS là gì?

CSS (viết tắt của Cascading Style Sheets — Bảng kiểu xếp tầng) là ngôn ngữ dùng để định dạng trình bày cho trang web: màu sắc, cỡ chữ, phông chữ, căn lề, bố cục, khoảng cách...

Phân công rõ ràng:

  • HTML: tạo cấu trúc, nội dung (đâu là tiêu đề, đoạn văn, bảng...).
  • CSS: định dạng trình bày (màu gì, cỡ bao nhiêu, nằm ở đâu...).

2. Vai trò của CSS

  • Tách nội dung khỏi trình bày: HTML giữ cấu trúc sạch, CSS lo phần "trang điểm".
  • Nhất quán toàn website: một file CSS dùng chung cho hàng trăm trang — đổi một chỗ, cả website đổi theo.
  • Dễ bảo trì: muốn đổi màu chủ đạo chỉ cần sửa một file CSS thay vì sửa từng trang.
  • Trang nhẹ, tải nhanh: trình duyệt lưu file CSS vào bộ nhớ đệm, các trang sau tải nhanh hơn.

3. Cú pháp CSS cơ bản

Một quy tắc CSS gồm bộ chọn (selector — chọn phần tử cần định dạng) và khối khai báo trong cặp ngoặc nhọn, mỗi khai báo có dạng thuộc tính: giá trị;:

p {
  color: red;
  font-size: 16px;
}

Quy tắc trên có nghĩa: mọi đoạn văn (bộ chọn p) đều có chữ màu đỏ, cỡ 16 pixel.

4. Ba cách đưa CSS vào trang web

CáchViết ở đâuVí dụPhạm vi
Trong thẻ
(inline)		Thuộc tính style của thẻ<p style="color: red;">Chỉ thẻ đó
Trong head
(internal)		Thẻ <style> trong <head><style> p { color: red; } </style>Cả trang đó
File ngoài
(external)		File .css riêng, liên kết bằng thẻ <link><link rel="stylesheet" href="style.css">Nhiều trang dùng chung

📌 Ghi nhớ

Ưu tiên dùng file CSS ngoài cho website nhiều trang (dễ bảo trì, nhất quán). CSS trong thẻ chỉ dùng cho trường hợp đặc biệt, đơn lẻ. Từ "Cascading" (xếp tầng) nghĩa là các quy tắc chồng lên nhau theo thứ tự ưu tiên — học kĩ ở Bài 17.

Tóm tắt toàn bài

  • CSS (Cascading Style Sheets): ngôn ngữ định dạng trình bày cho web.
  • Vai trò: tách nội dung khỏi trình bày; nhất quán toàn website; dễ bảo trì; tải nhanh.
  • Cú pháp: bộ chọn { thuộc tính: giá trị; }.
  • 3 cách nhúng: trong thẻ (style — một thẻ), trong head (thẻ style — cả trang), file ngoài (link — nhiều trang, nên dùng).
