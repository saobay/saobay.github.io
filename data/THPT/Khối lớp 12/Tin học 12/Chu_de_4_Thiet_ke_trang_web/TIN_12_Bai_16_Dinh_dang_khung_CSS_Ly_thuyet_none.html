Bài 16: Định dạng khung

Chủ đề 4: Giải quyết vấn đề với sự trợ giúp của máy tính — Kết nối tri thức với cuộc sống

1. Mô hình hộp (box model)

Mọi phần tử HTML đều được coi như một cái hộp gồm 4 lớp từ trong ra ngoài:

LớpThuộc tínhÝ nghĩa
Nội dungwidth, heightVùng chứa nội dung (chữ, ảnh...)
Đệm trongpaddingKhoảng cách giữa nội dung và viền
ViềnborderĐường viền bao quanh (dày, kiểu, màu)
Lề ngoàimarginKhoảng cách giữa hộp này với hộp khác (trong suốt)

2. Các thuộc tính chi tiết

  • Viền: viết gọn border: 2px solid red; (dày 2px, kiểu liền nét, màu đỏ). Kiểu viền: solid (liền), dashed (đứt nét), dotted (chấm), double (kép), none (không viền).
  • Bo góc: border-radius (ví dụ 10px; 50% tạo hình tròn cho ảnh vuông).
  • Căn giữa khối: margin: 0 auto; (trên dưới 0, trái phải tự động) — áp dụng cho khối có width xác định.
  • Viết gọn 4 phía (theo thứ tự trên → phải → dưới → trái, chiều kim đồng hồ): margin: 10px 20px 30px 40px;. Viết 2 giá trị: 10px 20px (trên+dưới 10px, trái+phải 20px). Viết 1 giá trị: cả 4 phía bằng nhau.
.hop {
  width: 300px;
  padding: 20px;
  border: 2px solid blue;
  border-radius: 10px;
  margin: 0 auto;
}

3. box-sizing

Mặc định (content-box), width chỉ tính phần nội dung — padding và border làm hộp rộng thêm ra ngoài. Với box-sizing: border-box;, width bao gồm cả padding và border — kích thước hộp đúng bằng width đã đặt, dễ tính toán bố cục.

📌 Ghi nhớ

Thứ tự từ trong ra ngoài: content → padding → border → margin. Viết gọn: border: dày kiểu màu; 4 phía theo chiều kim đồng hồ (trên, phải, dưới, trái). Nên dùng box-sizing: border-box để dễ tính kích thước.

Tóm tắt toàn bài

  • Box model: content (width/height) → padding (đệm trong) → border (viền) → margin (lề ngoài).
  • border: dày, kiểu (solid, dashed, dotted, double, none), màu; border-radius: bo góc.
  • margin: 0 auto: căn giữa khối; viết gọn 4 phía theo chiều kim đồng hồ.
  • box-sizing: border-box: width gồm cả padding và border.
