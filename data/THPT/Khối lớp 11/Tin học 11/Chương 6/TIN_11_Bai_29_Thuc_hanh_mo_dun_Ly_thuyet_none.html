1. Quy trình thực hành chia mô đun

Bài toán thực hành: Nhập điểm các môn của n học sinh. In ra điểm trung bình từng học sinh, chỉ số học sinh giỏi nhất và xếp loại từng học sinh (Giỏi/Khá/Trung bình).

Áp dụng làm mịn dần để chia thành các mô đun:

  • nhap_diem(n, m) → trả về bảng điểm.
  • tinh_trung_binh(diem) → trả về mảng trung bình.
  • tim_gioi_nhat(tb) → trả về chỉ số giỏi nhất.
  • xep_loai(tb) → trả về mảng xếp loại.

Nguyên tắc khi chia hàm:

  • Mỗi hàm một việc: nhập, tính, tìm, xếp loại tách riêng.
  • Hàm độc lập: chỉ giao tiếp qua tham số và giá trị trả về.
  • Tên gợi nhớ: đọc tên là biết chức năng.

2. Viết từng hàm và kiểm thử riêng (kiểm thử đơn vị)

Kiểm thử đơn vị: kiểm thử từng hàm độc lập trước khi ghép thành chương trình hoàn chỉnh.

def tinh_trung_binh(diem):
    tb = []
    for row in diem:
        s = 0
        for x in row:
            s = s + x
        tb.append(s / len(row))
    return tb

# Kiểm thử đơn vị cho hàm tinh_trung_binh
print(tinh_trung_binh([[8, 6], [9, 9]]))  # [7.0, 9.0]
print(tinh_trung_binh([[5, 7, 9]]))       # [7.0]
def xep_loai(tb):
    kq = []
    for d in tb:
        if d == max(d, 8):
            kq.append("Gioi")
        elif d == max(d, 6.5):
            kq.append("Kha")
        else:
            kq.append("Trung binh")
    return kq

# Kiểm thử đơn vị cho hàm xep_loai
print(xep_loai([9.0, 7.0, 5.0]))  # ['Gioi', 'Kha', 'Trung binh']

📌 Ghi nhớ

Điều kiện d >= 8 được viết thành d == max(d, 8) để tránh dùng >. Kiểm thử đơn vị giúp phát hiện lỗi ngay trong hàm, trước khi ghép chương trình.

3. Ghép các hàm thành chương trình hoàn chỉnh

def nhap_diem(n, m):
    diem = []
    for i in range(n):
        diem.append(list(map(float, input().split())))
    return diem

def tinh_trung_binh(diem):
    tb = []
    for row in diem:
        s = 0
        for x in row:
            s = s + x
        tb.append(s / len(row))
    return tb

def tim_gioi_nhat(tb):
    vmax = tb[0]
    vt = 0
    for i in range(1, len(tb)):
        if tb[i] == max(tb[i], vmax) and tb[i] != vmax:
            vmax = tb[i]
            vt = i
    return vt

def xep_loai(tb):
    kq = []
    for d in tb:
        if d == max(d, 8):
            kq.append("Gioi")
        elif d == max(d, 6.5):
            kq.append("Kha")
        else:
            kq.append("Trung binh")
    return kq

# Chương trình chính: gọi các hàm theo trình tự
n = int(input())
m = int(input())
diem = nhap_diem(n, m)
tb = tinh_trung_binh(diem)
print("Trung binh:", tb)
print("Gioi nhat:", tim_gioi_nhat(tb))
print("Xep loai:", xep_loai(tb))

4. Kiểm thử tích hợp (test toàn bộ chương trình)

Sau khi từng hàm đúng, kiểm thử tích hợp kiểm tra sự phối hợp giữa các hàm:

TestDữ liệuKết quả mong đợi
1n=2, m=2; 8 6 / 9 9TB [7.0, 9.0]; giỏi nhất 1; loại [Kha, Gioi]
2n=1, m=1; 10TB [10.0]; giỏi nhất 0; loại [Gioi]
Loại kiểm thửKiểm tra gì
Kiểm thử đơn vịTừng hàm chạy đúng độc lập
Kiểm thử tích hợpCác hàm phối hợp đúng với nhau

⚠️ Lỗi thường gặp

  • Gọi hàm sai thứ tự (tính trung bình trước khi nhập) → lỗi logic.
  • Truyền sai đối số (truyền diem cho hàm cần tb).
  • Quên return ở một hàm → hàm sau nhận None.

Tóm tắt toàn bài

  • Quy trình: chia bài toán con → viết mỗi con thành một hàm → kiểm thử đơn vị từng hàm → ghép lại → kiểm thử tích hợp.
  • Kiểm thử đơn vị: test từng hàm độc lập; tích hợp: test sự phối hợp giữa các hàm.
  • Lỗi hay gặp: sai thứ tự gọi, sai đối số, quên return.
