1. Độ phức tạp thời gian là gì?

Khi n (kích thước dữ liệu đầu vào) tăng lên, thời gian chạy của chương trình cũng tăng theo. Độ phức tạp thời gian là cách đánh giá số lượng phép tính cơ bản (phép so sánh, phép gán, phép tính số học...) mà thuật toán thực hiện, tính theo n.

Vì thời gian chạy thực tế còn phụ thuộc vào máy tính, người ta không đếm chính xác từng mili giây mà dùng kí hiệu O (O-lớn) để mô tả xu hướng tăng của thời gian chạy khi n tăng.

Ví dụ:

Thuật toán tìm kiếm tuần tự trong trường hợp xấu nhất phải so sánh cả n phần tử — ta nói nó có độ phức tạp O($n$). Thuật toán tìm kiếm nhị phân chỉ cần khoảng $\log_2 n$ lần so sánh — độ phức tạp O($\log n$).

2. Các độ phức tạp thường gặp

Kí hiệuTên gọiVí dụ
O($1$)Hằng sốTruy cập a[i], tính a[0] + a[1]
O($\log n$)LogaritTìm kiếm nhị phân
O($n$)Tuyến tínhDuyệt mảng, tìm kiếm tuần tự, tính tổng
O($n \log n$)Tuyến tính logaritCác thuật toán sắp xếp nhanh
O($n^2$)Bậc haiNổi bọt, chọn, chèn (hai vòng lặp lồng nhau)
O($2^n$)Hàm mũLiệt kê mọi tập con (không thực tế với n lớn)

Thứ tự tăng dần (từ nhanh đến chậm) khi n lớn:

O($1$) < O($\log n$) < O($n$) < O($n \log n$) < O($n^2$) < O($2^n$)

📌 Ghi nhớ

Với n lớn, sự chênh lệch là khổng lồ: $n = 10^6$ thì O($n$) cần $10^6$ phép tính, O($n^2$) cần $10^{12}$ phép tính, còn O($\log n$) chỉ cần khoảng 20 phép tính!

3. Quy tắc xác định độ phức tạp

Giả sử ta đếm được số phép tính cơ bản là một hàm của n, ví dụ $3n^2 + 5n + 100$. Để đưa về kí hiệu O, áp dụng hai quy tắc:

  • Quy tắc 1 — bỏ hằng số: bỏ mọi hệ số hằng và số hạng hằng. Ví dụ: $3n^2$ thành $n^2$; $5n$ thành $n$.
  • Quy tắc 2 — giữ số hạng trội: khi n lớn, chỉ giữ số hạng tăng nhanh nhất. Ví dụ: $n^2 + n$ thành $n^2$.

Ví dụ:

  • $3n^2 + 5n + 100$ → O($n^2$)
  • $7n + 1000$ → O($n$)
  • $0{,}5n^2 + 3n$ → O($n^2$)
  • $100$ (không phụ thuộc n) → O($1$)

4. Phân tích độ phức tạp của một số đoạn chương trình

Một vòng lặp duyệt n lần → O($n$):

s = 0
for x in a:        # lặp n lần
    s = s + x
# Độ phức tạp: O(n)

Hai vòng lặp lồng nhau, mỗi vòng n lần → O($n^2$):

c = 0
for i in range(n):
    for j in range(n):   # n * n = n^2 lần
        c = c + 1
# Độ phức tạp: O(n^2)

Vòng lặp mà biến tăng gấp đôi mỗi lần → O($\log n$):

i = 1
while i != n:
    i = i * 2        # 1, 2, 4, 8, ... : khoảng log2(n) lần
# Độ phức tạp: O(log n)

Vòng lặp với số lần không phụ thuộc n → O($1$):

for i in range(1000):   # luôn lặp đúng 1000 lần
    print(i)
# Độ phức tạp: O(1)

📌 Ghi nhớ

Đếm số lần lặp theo n rồi rút gọn bằng hai quy tắc: một vòng lặp thường là O($n$), hai vòng lồng nhau thường là O($n^2$), biến tăng gấp đôi mỗi lần là O($\log n$), số lần cố định là O($1$).

Tóm tắt toàn bài

  • Độ phức tạp thời gian: số phép tính cơ bản theo kích thước dữ liệu n, biểu diễn bằng kí hiệu O.
  • Hai quy tắc: bỏ hằng số; chỉ giữ số hạng tăng nhanh nhất.
  • Thứ tự từ nhanh đến chậm: O($1$) < O($\log n$) < O($n$) < O($n \log n$) < O($n^2$) < O($2^n$).
  • Nhận diện nhanh: một vòng lặp → O($n$); hai vòng lồng nhau → O($n^2$); biến tăng gấp đôi → O($\log n$).
