1. Mô đun là gì?

Mô đun (module) là một đơn vị chương trình độc lập thực hiện một chức năng xác định. Trong Python, mô đun thường được thể hiện bằng một hàm (function).

Thiết kế chương trình theo mô đun là chia chương trình thành các mô đun (hàm), mỗi hàm làm một việc rõ ràng; chương trình chính chỉ gọi các hàm theo đúng trình tự.

Ví dụ: chương trình tính trung bình lớp

  • nhap_diem(): nhập và trả về bảng điểm.
  • tinh_trung_binh(diem): nhận bảng điểm, trả về mảng trung bình.
  • tim_gioi_nhat(tb): nhận mảng trung bình, trả về chỉ số giỏi nhất.
  • Chương trình chính: gọi lần lượt ba hàm trên rồi in kết quả.

2. Hàm trong Python: tham số và giá trị trả về

Cú pháp định nghĩa hàm:

def ten_ham(tham_so_1, tham_so_2):
    # thân hàm: các lệnh xử lí
    return ket_qua
  • Tham số (parameter): dữ liệu đầu vào của hàm, khai báo trong ngoặc đơn.
  • Giá trị trả về: kết quả hàm gửi lại cho nơi gọi, bằng lệnh return.
  • Đối số (argument): giá trị cụ thể truyền vào khi gọi hàm.
def tinh_tong(a):
    s = 0
    for x in a:
        s = s + x
    return s

diem = [8, 7, 9]
print(tinh_tong(diem))  # 24 (diem là đối số, a là tham số)

📌 Ghi nhớ

Hàm không có return sẽ trả về None. Biến tạo trong hàm là biến cục bộ, không dùng được bên ngoài hàm.

3. Nguyên tắc thiết kế mô đun tốt

4. Ví dụ đầy đủ: chương trình quản lí điểm theo mô đun

def nhap_diem(n, m):
    diem = []
    for i in range(n):
        diem.append(list(map(float, input().split())))
    return diem

def tinh_trung_binh(diem):
    tb = []
    for row in diem:
        s = 0
        for x in row:
            s = s + x
        tb.append(s / len(row))
    return tb

def tim_gioi_nhat(tb):
    vmax = tb[0]
    vt = 0
    for i in range(1, len(tb)):
        if tb[i] == max(tb[i], vmax) and tb[i] != vmax:
            vmax = tb[i]
            vt = i
    return vt

# Chương trình chính
n = int(input())
m = int(input())
diem = nhap_diem(n, m)
tb = tinh_trung_binh(diem)
print("Giỏi nhất:", tim_gioi_nhat(tb))

⚠️ Lỗi thường gặp

  • Quên return nên hàm trả về None.
  • Dùng biến cục bộ bên ngoài hàm → lỗi NameError.
  • Truyền sai số lượng đối số khi gọi hàm → lỗi TypeError.
  • Đặt tên hàm trùng với hàm có sẵn (ví dụ sum, max).

Tóm tắt toàn bài

  • Mô đun: đơn vị chương trình độc lập, trong Python thường là một hàm.
  • Hàm: nhận dữ liệu qua tham số, trả kết quả bằng return.
  • Nguyên tắc: một mô đun một việc; độc lập; giao tiếp qua tham số/return; tên gợi nhớ.
  • Lợi ích: dễ hiểu, dễ kiểm thử từng hàm, tái sử dụng.
