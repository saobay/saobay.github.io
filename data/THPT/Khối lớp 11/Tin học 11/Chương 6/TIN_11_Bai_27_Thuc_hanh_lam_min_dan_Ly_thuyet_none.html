Bài 27: Thực hành thiết kế chương trình theo phương pháp làm mịn dần

Chương 6: Kĩ thuật lập trình — sách Kết nối tri thức với cuộc sống

1. Quy trình thực hành thiết kế theo làm mịn dần

Trong bài thực hành này, ta áp dụng đầy đủ 5 bước của phương pháp làm mịn dần vào một bài toán cụ thể: phân tích → chia bài toán con → làm mịn → viết code → kiểm thử.

Bài toán thực hành: Nhập điểm các môn của n học sinh. In ra điểm trung bình của từng học sinh và chỉ số của học sinh có điểm trung bình cao nhất.

Bước 1 — Phân tích:

  • Input: số học sinh n, số môn m, bảng điểm n hàng m cột.
  • Output: trung bình từng học sinh + chỉ số học sinh giỏi nhất.
  • Quan hệ: trung bình = tổng điểm các môn / số môn; giỏi nhất = trung bình lớn nhất.

2. Chia bài toán con và làm mịn

Bước 2 — Chia thành 3 bài toán con (mức 1):

  1. Nhập bảng điểm.
  2. Tính điểm trung bình từng học sinh.
  3. Tìm học sinh có trung bình cao nhất và in kết quả.

Bước 3 — Làm mịn (mức 2):

  • 1.1: Nhập n, m.
  • 1.2: Nhập n dòng, mỗi dòng m số.
  • 2.1: Với mỗi học sinh, tính tổng điểm các môn.
  • 2.2: Chia tổng cho m được trung bình.
  • 3.1: Khởi tạo max = trung bình đầu, vt = 0.
  • 3.2: Duyệt các học sinh còn lại, cập nhật max và vt.
  • 3.3: In trung bình từng học sinh và chỉ số vt.

📌 Ghi nhớ

Mỗi bước ở mức 2 chỉ cần 1–3 lệnh Python là viết được — đó là dấu hiệu đã làm mịn đủ.

3. Viết code (bước 4)

# Bài toán con 1: nhập bảng điểm
n = int(input())
m = int(input())
diem = []
for i in range(n):
    diem.append(list(map(float, input().split())))

# Bài toán con 2: tính trung bình từng học sinh
tb = []
for i in range(n):
    s = 0
    for x in diem[i]:
        s = s + x
    tb.append(s / m)
    print("HS", i, ":", s / m)

# Bài toán con 3: tìm học sinh giỏi nhất
vmax = tb[0]
vt = 0
for i in range(1, n):
    if tb[i] == max(tb[i], vmax) and tb[i] != vmax:
        vmax = tb[i]
        vt = i
print("Giỏi nhất:", vt)

4. Kiểm thử (bước 5)

Chạy thử với dữ liệu mẫu nhỏ và kiểm tra từng bài toán con:

TestDữ liệu vàoKết quả mong đợiKiểm tra
1n=2, m=2; điểm: 8 6 / 9 9TB: 7.0, 9.0; giỏi nhất: 1Bài toán con 2, 3
2n=1, m=3; điểm: 5 7 9TB: 7.0; giỏi nhất: 0Trường hợp biên n=1
3n=3, m=1; điểm: 8 / 8 / 8TB: 8.0, 8.0, 8.0; giỏi nhất: 0Điểm bằng nhau

⚠️ Lỗi thường gặp khi thực hành

  • Nhập sai số lượng số mỗi dòng (không bằng m) → kiểm tra dữ liệu nhập.
  • Chia cho m nhưng m = 0 → lỗi chia cho 0.
  • Quên khởi tạo vmax trước vòng lặp tìm max.
  • In nhầm chỉ số (bắt đầu từ 0) với số thứ tự học sinh (bắt đầu từ 1).

5. Bài tập tự thực hành

Áp dụng 5 bước cho bài toán: nhập mảng n số nguyên, đếm số lượng số chẵn và tính tổng các số chẵn.

Gợi ý phân tích:

  • Mức 1: Nhập mảng → Đếm và tính tổng số chẵn → In kết quả.
  • Mức 2: Nhập n, nhập n số; khởi tạo đếm = 0, tổng = 0; duyệt mảng, nếu chẵn thì đếm tăng 1 và cộng vào tổng.
  • Mức 3: viết code Python (dùng % 2 == 0 để kiểm tra chẵn).
  • Kiểm thử: mảng [1, 2, 3, 4] → đếm = 2, tổng = 6; mảng rỗng → đếm = 0, tổng = 0.

Tóm tắt toàn bài

  • Quy trình 5 bước: phân tích input/output → chia 3 bài toán con → làm mịn đến 1–3 lệnh → viết code → kiểm thử từng phần.
  • Kiểm thử gồm: dữ liệu thường, trường hợp biên (n = 1), trường hợp đặc biệt (điểm bằng nhau).
  • Lỗi hay gặp: nhập sai định dạng, chia cho 0, quên khởi tạo, nhầm chỉ số 0/1.
