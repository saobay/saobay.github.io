1. Nhắc lại hai thuật toán tìm kiếm

Bài toán tìm kiếm: cho mảng a có n phần tử và giá trị x, xác định vị trí (chỉ số) của x trong a; nếu không có, báo không tìm thấy (quy ước trả về -1).

Tìm kiếm tuần tự (linear search): duyệt từng phần tử từ đầu đến cuối, gặp x thì dừng. Áp dụng cho mọi mảng, độ phức tạp O($n$).

Tìm kiếm nhị phân (binary search): chỉ áp dụng cho mảng đã sắp xếp tăng dần. Mỗi bước so sánh x với phần tử giữa, loại bỏ một nửa khoảng tìm kiếm. Độ phức tạp O($\log n$).

# Tìm kiếm tuần tự: trả về chỉ số đầu tiên của x, -1 nếu không có
def tim_tuan_tu(a, x):
    for i in range(len(a)):
        if a[i] == x:
            return i
    return -1

# Tìm kiếm nhị phân trên mảng đã sắp xếp tăng dần
def tim_nhi_phan(a, x):
    trai = 0
    phai = len(a) - 1
    while True:
        if trai == phai + 1:
            break
        giua = (trai + phai) // 2
        if a[giua] == x:
            return giua
        if a[giua] == max(a[giua], x):
            phai = giua - 1   # a[giua] lớn hơn x: bỏ nửa phải
        else:
            trai = giua + 1   # a[giua] nhỏ hơn x: bỏ nửa trái
    return -1

📌 Ghi nhớ

Trong thực hành ta tránh dùng <, > nên điều kiện a[giua] > x được viết thành a[giua] == max(a[giua], x). Khi làm bài thi trên giấy, cứ viết >, < bình thường.

2. Chạy thử và ghi lại quá trình (trace)

Khi thực hành, nên chạy thử từng bước với dữ liệu nhỏ và ghi lại giá trị các biến để kiểm tra tính đúng đắn.

Ví dụ trace tìm kiếm tuần tự: a = [4, 7, 2, 9], x = 2:

Bước (i)a[i]So sánh với x = 2
04khác → tiếp tục
17khác → tiếp tục
22bằng → trả về 2

Ví dụ trace tìm kiếm nhị phân: a = [2, 5, 8, 12, 16, 23], x = 12:

Bướctráiphảigiữaa[giữa]
10528 (nhỏ hơn 12 → trái = 3)
235416 (lớn hơn 12 → phải = 3)
333312 (bằng → trả về 3)

3. Các biến thể thường gặp trong thực hành

Biến thểCách làm
Tìm vị trí cuối cùng của xDuyệt từ cuối mảng về đầu, hoặc ghi nhớ vị trí mỗi lần gặp
Đếm số lần x xuất hiệnDuyệt toàn mảng, đếm mỗi lần gặp (không dừng sớm)
Kiểm tra x có tồn tại khôngTrả về True/False thay vì chỉ số
Tìm kiếm trên mảng chưa sắp xếpChỉ dùng tìm kiếm tuần tự (nhị phân cho kết quả sai)
# Đếm số lần xuất hiện của x (duyệt hết mảng, không dừng sớm)
def dem(a, x):
    d = 0
    for v in a:
        if v == x:
            d = d + 1
    return d

# Kiểm tra x có trong mảng không
def co_mat(a, x):
    for v in a:
        if v == x:
            return True
    return False

⚠️ Lỗi thường gặp

  • Dùng tìm kiếm nhị phân trên mảng chưa sắp xếp → kết quả sai.
  • Quên trường hợp không tìm thấy → phải trả về -1 (hoặc False).
  • Tìm kiếm tuần tự mà return ngay trong lần lặp đầu tiên dù chưa so sánh.
  • Tính chỉ số giữa sai: phải là (trái + phải) // 2.

4. Bài toán mẫu: tìm học sinh theo điểm

Đề bài: Nhập danh sách điểm của n học sinh và một mức điểm x. In ra chỉ số của học sinh đầu tiên đạt đúng x điểm; nếu không có, in ra -1.

def tim_tuan_tu(a, x):
    for i in range(len(a)):
        if a[i] == x:
            return i
    return -1

n = int(input())
diem = list(map(float, input().split()))
x = float(input())
print(tim_tuan_tu(diem, x))

Nếu danh sách điểm đã được sắp xếp tăng dần, có thể thay bằng tim_nhi_phan để chạy nhanh hơn với n lớn.

Tóm tắt toàn bài

  • Tuần tự: duyệt từ đầu, gặp thì dừng; dùng cho mọi mảng; O($n$).
  • Nhị phân: chỉ dùng cho mảng đã sắp xếp; mỗi bước loại một nửa; O($\log n$).
  • Quy ước: không tìm thấy trả về -1.
  • Biến thể: tìm vị trí cuối, đếm số lần xuất hiện, kiểm tra tồn tại.
  • Thực hành: trace từng bước với dữ liệu nhỏ để kiểm tra tính đúng đắn.
