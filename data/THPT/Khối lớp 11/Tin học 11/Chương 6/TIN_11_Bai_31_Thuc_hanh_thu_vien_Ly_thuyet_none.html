Chương 6: Kĩ thuật lập trình — sách Kết nối tri thức với cuộc sống

1. Bài toán thực hành

Sử dụng thư viện toan_hoc.py đã thiết lập ở Bài 30 để viết chương trình quản lí điểm kiểm tra của một lớp:

  • Nhập: số học sinh và điểm của từng học sinh.
  • Tính: điểm trung bình cả lớp, điểm cao nhất, điểm thấp nhất.
  • Xếp loại: từng học sinh theo thang Giỏi/Khá/Trung bình/Yếu.

File thư viện toan_hoc.py (đã có):

def tinh_tong(a):
    s = 0
    for x in a:
        s = s + x
    return s

def tinh_trung_binh(a):
    return tinh_tong(a) / len(a)

def tim_max(a):
    mx = a[0]
    for x in a:
        if x == max(x, mx):
            mx = x
    return mx

def tim_min(a):
    mn = a[0]
    for x in a:
        if x == min(x, mn):
            mn = x
    return mn

def xep_loai(d):
    if d == max(d, 8):
        return "Gioi"
    if d == max(d, 6.5):
        return "Kha"
    if d == max(d, 5):
        return "Trung binh"
    return "Yeu"

2. Chương trình chính sử dụng thư viện

import toan_hoc as th

n = int(input("So hoc sinh: "))
diem = []
for i in range(n):
    d = float(input("Diem HS " + str(i + 1) + ": "))
    diem.append(d)

print("Diem TB ca lop:", th.tinh_trung_binh(diem))
print("Diem cao nhat:", th.tim_max(diem))
print("Diem thap nhat:", th.tim_min(diem))
for i in range(n):
    print("HS", i + 1, ":", diem[i], th.xep_loai(diem[i]))

Chạy thử với n = 3, điểm 8, 6, 4:

So hoc sinh: 3
Diem HS 1: 8
Diem HS 2: 6
Diem HS 3: 4
Diem TB ca lop: 6.0
Diem cao nhat: 8
Diem thap nhat: 4
HS 1 : 8.0 Gioi
HS 2 : 6.0 Kha
HS 3 : 4.0 Yeu

📌 Ghi nhớ

  • Chương trình chính không cần biết hàm được viết thế nào — chỉ cần biết tên hàm và cách dùng.
  • Muốn thêm tính năng (ví dụ: đếm số học sinh Giỏi) → viết thêm hàm vào thư viện, rồi gọi từ chương trình chính.

3. Mở rộng thư viện

Thêm hàm dem_gioi(a) đếm số học sinh đạt loại Giỏi vào toan_hoc.py:

def dem_gioi(a):
    dem = 0
    for d in a:
        if xep_loai(d) == "Gioi":
            dem = dem + 1
    return dem

Trong chương trình chính chỉ cần thêm một dòng:

print("So HS dat loai Gioi:", th.dem_gioi(diem))

⚠️ Lỗi thường gặp

  • Sửa thư viện nhưng chưa lưu file → chương trình chính vẫn chạy bản cũ.
  • Thêm hàm mới nhưng quên kiểm thử → lỗi lan sang chương trình chính.
  • Đặt tên hàm mới trùng hàm cũ → hàm cũ bị ghi đè.

Tóm tắt toàn bài

  • Sử dụng thư viện: import toan_hoc as th, gọi th.ten_ham().
  • Chương trình chính chỉ lo nhập/xuất và điều phối; logic tính toán nằm trong thư viện.
  • Mở rộng: thêm hàm vào file thư viện, kiểm thử rồi mới dùng trong chương trình chính.
