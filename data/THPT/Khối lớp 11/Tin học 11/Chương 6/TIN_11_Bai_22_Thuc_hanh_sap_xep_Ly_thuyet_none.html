1. Nhắc lại ba thuật toán sắp xếp đơn giản

Sắp xếp nổi bọt (bubble sort): lặp đi lặp lại việc so sánh từng cặp phần tử kề nhau và đổi chỗ nếu chúng sai thứ tự. Sau mỗi lượt, phần tử lớn nhất "nổi" lên cuối dãy.

Sắp xếp chọn (selection sort): mỗi lượt chọn phần tử nhỏ nhất trong phần chưa sắp xếp và đổi chỗ với phần tử đầu của phần đó.

Sắp xếp chèn (insertion sort): duyệt từng phần tử và chèn nó vào đúng vị trí trong phần đã sắp xếp ở phía trước.

Cả ba thuật toán đều có độ phức tạp O($n^2$) trong trường hợp xấu nhất.

# Sắp xếp nổi bọt (tăng dần), tránh dùng dấu lớn hơn
def bubble_sort(a):
    n = len(a)
    for i in range(n):
        for j in range(n - 1 - i):
            if a[j] == max(a[j], a[j + 1]) and a[j] != a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a

# Sắp xếp chọn (tăng dần)
def selection_sort(a):
    n = len(a)
    for i in range(n):
        k = i
        for j in range(i + 1, n):
            if a[j] == min(a[j], a[k]):
                k = j
        a[i], a[k] = a[k], a[i]
    return a

📌 Ghi nhớ

Điều kiện a[j] > a[j+1] được viết lại thành a[j] == max(a[j], a[j+1]) and a[j] != a[j+1] để tránh dùng >. Trên giấy thi, cứ viết > bình thường.

2. Trace quá trình sắp xếp (theo dõi từng bước)

Ví dụ nổi bọt với a = [5, 3, 8, 1] (lượt 1, j chạy từ 0 đến 2):

jSo sánhĐổi chỗ?Mảng sau bước
05 và 3có[3, 5, 8, 1]
15 và 8không[3, 5, 8, 1]

Hết lượt 1, số lớn nhất (8) đã về cuối. Tiếp tục lượt 2, 3 cho đến khi mảng sắp xếp xong: [1, 3, 5, 8].

Ví dụ sắp xếp chọn với a = [5, 3, 8, 1]:

3. Đếm số lần so sánh và đổi chỗ

Trong thực hành, người ta thường yêu cầu đếm số lần đổi chỗ hoặc số lần so sánh để đánh giá thuật toán.

# Nổi bọt có đếm số lần đổi chỗ
def bubble_sort_dem(a):
    n = len(a)
    dem = 0
    for i in range(n):
        for j in range(n - 1 - i):
            if a[j] == max(a[j], a[j + 1]) and a[j] != a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                dem = dem + 1
    return dem

print(bubble_sort_dem([5, 3, 8, 1]))  # 4

Số lần so sánh của nổi bọt và chọn (không tính tối ưu dừng sớm): với mảng n phần tử, tổng số cặp so sánh là $(n-1) + (n-2) + \ldots + 1 = \frac{n(n-1)}{2}$.

Ví dụ:

Với $n = 4$: số lần so sánh là $3 + 2 + 1 = 6$. Với $n = 5$: $4 + 3 + 2 + 1 = 10$ lần.

4. Sắp xếp giảm dần và các biến thể

Muốn sắp xếp giảm dần, chỉ cần đổi chiều so sánh: đổi chỗ khi phần tử trước nhỏ hơn phần tử sau.

# Nổi bọt sắp xếp giảm dần
def bubble_sort_giam(a):
    n = len(a)
    for i in range(n):
        for j in range(n - 1 - i):
            if a[j] == min(a[j], a[j + 1]) and a[j] != a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a

print(bubble_sort_giam([5, 3, 8, 1]))  # [8, 5, 3, 1]

Sắp xếp giảm dầnĐổi chiều điều kiện so sánh
Đếm số lần đổi chỗThêm biến đếm, tăng mỗi khi đổi chỗ
Dừng sớm khi đã sắp xếpDùng cờ hiệu: hết một lượt không đổi chỗ nào thì dừng
Sắp xếp chuỗiSo sánh chuỗi theo thứ tự từ điển (mặc định của Python)

⚠️ Lỗi thường gặp

  • Phạm vi vòng lặp trong sai: range(n - 1 - i) chứ không phải range(n) (tránh so sánh a[n-1] với a[n] gây lỗi).
  • Quên cập nhật chỉ số phần tử nhỏ nhất trong sắp xếp chọn.
  • Nhầm chiều so sánh khi chuyển từ tăng dần sang giảm dần.

5. Bài toán mẫu: xếp hạng học sinh

Đề bài: Nhập điểm trung bình của n học sinh. Sắp xếp giảm dần để xếp hạng và in ra danh sách sau khi sắp xếp.

def sap_xep_giam(a):
    n = len(a)
    for i in range(n):
        for j in range(n - 1 - i):
            if a[j] == min(a[j], a[j + 1]) and a[j] != a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a

n = int(input())
diem = list(map(float, input().split()))
print(sap_xep_giam(diem))

Tóm tắt toàn bài

  • Nổi bọt: so sánh cặp kề nhau, đổi chỗ nếu sai thứ tự; phần tử lớn "nổi" lên cuối.
  • Chọn: mỗi lượt chọn nhỏ nhất trong phần chưa sắp xếp, đổi với đầu phần đó.
  • Chèn: chèn từng phần tử vào đúng vị trí trong phần đã sắp xếp.
  • Số lần so sánh: $n(n-1)/2$ với mảng $n$ phần tử.
  • Thực hành: trace từng bước, đếm đổi chỗ, đổi chiều sắp xếp, dừng sớm bằng cờ hiệu.
