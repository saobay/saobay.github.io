1. Thư viện là gì? Vì sao cần thư viện?

Thư viện (library) là tập hợp các mô đun/hàm đã được viết sẵn, kiểm thử kĩ và dùng chung cho nhiều chương trình.

Vì sao cần thư viện:

  • Không viết lại: dùng ngay hàm có sẵn thay vì tự viết lại từ đầu.
  • Đáng tin cậy: hàm trong thư viện đã được kiểm thử kĩ.
  • Tiết kiệm thời gian: tập trung vào logic chính của bài toán.

Ví dụ:

Thay vì tự viết hàm tính căn bậc hai, ta dùng math.sqrt(). Thay vì tự viết tìm kiếm nhị phân, ta dùng bisect.bisect_left().

2. Sử dụng thư viện có sẵn trong Python

Dùng lệnh import để nạp thư viện:

import math
print(math.sqrt(16))      # 4.0
print(math.pi)            # 3.141592653589793

import bisect
a = [2, 5, 8, 12]
print(bisect.bisect_left(a, 8))  # 2

from math import sqrt, pi
print(sqrt(25))           # 5.0 (không cần tiền tố math.)
print(pi)
Cách importÝ nghĩa
import mathNạp cả thư viện, gọi qua tiền tố math.
from math import sqrtChỉ nạp hàm sqrt, gọi trực tiếp
import math as mĐặt tên ngắn gọn m cho thư viện

📌 Ghi nhớ

from math import * nạp tất cả nhưng dễ trùng tên — nên liệt kê rõ hàm cần dùng.

3. Tự thiết lập thư viện riêng

Các bước tạo thư viện toan_hoc.py của riêng mình:

  1. Viết file toan_hoc.py chứa các hàm dùng chung.
  2. Đặt file cùng thư mục với chương trình chính (hoặc nơi Python tìm thấy).
  3. import và sử dụng trong chương trình chính.

File toan_hoc.py:

def tinh_tong(a):
    s = 0
    for x in a:
        s = s + x
    return s

def tim_max(a):
    mx = a[0]
    for x in a:
        if x == max(x, mx):
            mx = x
    return mx

Chương trình chính main.py:

import toan_hoc

diem = [8, 7, 9, 6]
print(toan_hoc.tinh_tong(diem))  # 30
print(toan_hoc.tim_max(diem))    # 9

Quy tắc đặt tên file thư viện:

  • Tên file là tên thư viện (không có .py khi import).
  • Chỉ dùng chữ cái, số và gạch dưới; không trùng tên thư viện chuẩn.

⚠️ Lỗi thường gặp

  • File thư viện không cùng thư mục → lỗi ModuleNotFoundError.
  • Quên tiền tố khi dùng import math (viết sqrt(16) thay vì math.sqrt(16)).
  • Trùng tên hàm của mình với hàm thư viện → hàm thư viện bị ghi đè.

Tóm tắt toàn bài

  • Thư viện: tập hợp hàm viết sẵn, dùng chung cho nhiều chương trình.
  • Sử dụng: import math, from math import sqrt, import math as m.
  • Tự tạo: viết file .py chứa các hàm, đặt cùng thư mục, rồi import.
  • Lợi ích: không viết lại, đáng tin cậy, tiết kiệm thời gian.
