1. SQL là gì?

SQL (Structured Query Language — Ngôn ngữ truy vấn có cấu trúc) là ngôn ngữ chuẩn dùng để định nghĩa, truy vấn và cập nhật dữ liệu trong các cơ sở dữ liệu quan hệ. Hầu hết các hệ quản trị CSDL quan hệ (MySQL, SQL Server, Oracle, PostgreSQL...) đều dùng SQL.

Trong bài này ta làm việc với bảng HOCSINH mẫu:

MaHSHotenLopDiemTB
HS01An11A18.5
HS02Binh11A17.0
HS03Cuong11A29.0
HS04Dung11A26.5
HS05Hoa11A19.5

2. Các nhóm câu lệnh SQL

NhómChức năngCâu lệnh chính
Định nghĩa dữ liệu (DDL)Tạo, sửa, xóa cấu trúc bảngCREATE TABLE, ALTER TABLE, DROP TABLE
Thao tác dữ liệu (DML)Thêm, sửa, xóa dữ liệuINSERT, UPDATE, DELETE
Truy vấn dữ liệu (DQL)Khai thác, tra cứu dữ liệuSELECT
Kiểm soát dữ liệu (DCL)Phân quyền truy cậpGRANT, REVOKE

📌 Ghi nhớ

SELECT là câu lệnh truy vấn (chỉ đọc dữ liệu, không làm thay đổi bảng). INSERT, UPDATE, DELETE là các lệnh làm thay đổi dữ liệu trong bảng.

3. Truy vấn dữ liệu với SELECT

Cú pháp cơ bản:

SELECT , , ...
FROM 
WHERE <điều kiện>
ORDER BY  ASC | DESC;

Ví dụ trên bảng HOCSINH:

-- Lấy họ tên và lớp của mọi học sinh
SELECT Hoten, Lop FROM HOCSINH;

-- Lấy mọi cột của học sinh lớp 11A1
SELECT * FROM HOCSINH WHERE Lop = '11A1';

-- Học sinh có điểm trung bình từ 8 đến 10
SELECT Hoten, DiemTB FROM HOCSINH
WHERE DiemTB BETWEEN 8 AND 10;

-- Học sinh lớp 11A1, xếp theo điểm giảm dần
SELECT Hoten, DiemTB FROM HOCSINH
WHERE Lop = '11A1'
ORDER BY DiemTB DESC;

Các phép so sánh trong mệnh đề WHERE: = (bằng), != (khác), BETWEEN a AND b (trong khoảng), LIKE (so khớp mẫu với kí tự đại diện %), IN (thuộc danh sách), IS NULL (chưa có giá trị). Kết hợp nhiều điều kiện bằng AND, OR, NOT.

-- Họ tên bắt đầu bằng chữ T
SELECT Hoten FROM HOCSINH WHERE Hoten LIKE 'T%';

-- Học sinh lớp 11A1 hoặc 11A2 có điểm khác 10
SELECT Hoten FROM HOCSINH
WHERE Lop IN ('11A1', '11A2') AND DiemTB != 10;

Sắp xếp kết quả: ORDER BY kèm ASC (tăng dần — mặc định) hoặc DESC (giảm dần).

Hàm gộp và nhóm: COUNT (đếm), SUM (tổng), AVG (trung bình), MIN, MAX. Dùng GROUP BY để tính gộp theo từng nhóm:

-- Đếm số học sinh mỗi lớp
SELECT Lop, COUNT(*) FROM HOCSINH
GROUP BY Lop;
-- Kết quả: 11A1 | 3
--          11A2 | 2

-- Điểm trung bình của lớp 11A1
SELECT AVG(DiemTB) FROM HOCSINH
WHERE Lop = '11A1';   -- (8.5 + 7.0 + 9.5) / 3 = 8.33

📌 Ghi nhớ

WHERE lọc hàng trước khi tính toán; GROUP BY gom hàng thành nhóm để dùng hàm gộp; ORDER BY sắp xếp kết quả cuối cùng.

4. Cập nhật dữ liệu: INSERT, UPDATE, DELETE

-- Thêm một học sinh mới
INSERT INTO HOCSINH (MaHS, Hoten, Lop, DiemTB)
VALUES ('HS06', 'Lan', '11A2', 8.0);

-- Sửa điểm của học sinh HS02 thành 7.5
UPDATE HOCSINH
SET DiemTB = 7.5
WHERE MaHS = 'HS02';

-- Xóa học sinh có mã HS04
DELETE FROM HOCSINH
WHERE MaHS = 'HS04';

⚠️ Cẩn thận!

UPDATE hoặc DELETE không có mệnh đề WHERE sẽ tác động lên mọi hàng của bảng. Luôn kiểm tra điều kiện WHERE trước khi chạy!

Tóm tắt toàn bài

  • SQL là ngôn ngữ chuẩn để làm việc với CSDL quan hệ.
  • 4 nhóm lệnh: DDL (CREATE/ALTER/DROP TABLE), DML (INSERT/UPDATE/DELETE), DQL (SELECT), DCL (GRANT/REVOKE).
  • Truy vấn: SELECT ... FROM ... WHERE ... GROUP BY ... ORDER BY ....
  • WHERE: =, !=, BETWEEN, LIKE, IN, IS NULL, kết hợp bằng AND/OR/NOT.
  • Hàm gộp: COUNT, SUM, AVG, MIN, MAX (thường đi với GROUP BY).
  • Cập nhật: INSERT INTO ... VALUES, UPDATE ... SET ... WHERE, DELETE FROM ... WHERE — luôn cẩn thận với WHERE!
