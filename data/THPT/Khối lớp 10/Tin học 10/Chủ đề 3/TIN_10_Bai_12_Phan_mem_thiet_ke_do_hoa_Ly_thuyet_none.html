1. Hai loại đồ họa máy tính

Đồ họa máy tính được chia thành hai loại chính: đồ họa raster (bitmap) và đồ họa vector.

1.1. Đồ họa raster

Ảnh raster được cấu tạo từ một lưới các điểm ảnh (pixel); mỗi pixel lưu một màu sắc. Khi phóng to quá mức, ta sẽ nhìn thấy từng ô pixel vuông vức — hiện tượng vỡ ảnh (răng cưa). Ảnh raster có độ chi tiết cao, màu sắc phong phú nên phù hợp với ảnh chụp, tranh vẽ phức tạp; nhược điểm là dung lượng thường lớn và phóng to bị vỡ.

Các định dạng raster phổ biến: PNG, JPEG (JPG), BMP, GIF. Phần mềm raster tiêu biểu: Paint, Photoshop, GIMP.

1.2. Đồ họa vector

Ảnh vector được định nghĩa bằng các đối tượng hình học (điểm, đoạn thẳng, đường cong, đa giác, hình tròn...) và các công thức toán học mô tả chúng. Máy tính vẽ lại hình từ công thức ở mọi tỉ lệ nên phóng to bao nhiêu cũng không bị vỡ, file thường rất nhẹ. Mỗi đối tượng là độc lập: có thể chọn, di chuyển, tô màu, thay đổi kích thước riêng mà không ảnh hưởng đối tượng khác.

Đồ họa vector phù hợp với logo, biểu tượng, sơ đồ, chữ nghệ thuật, minh họa. Định dạng vector phổ biến: SVG, AI, CDR, EPS. Phần mềm vector tiêu biểu: Inkscape, Adobe Illustrator, CorelDRAW.

📌 Ghi nhớ

Raster = lưới pixel (phóng to vỡ); Vector = đối tượng + công thức (phóng to không vỡ). Logo, biển hiệu khổ lớn nên dùng vector.

2. Phần mềm Inkscape

Inkscape là phần mềm thiết kế đồ họa vector miễn phí, mã nguồn mở, chạy trên Windows, macOS và Linux. Trang chủ: inkscape.org. Định dạng file gốc của Inkscape là SVG (chuẩn mở, trình duyệt web cũng mở được).

  • Miễn phí, hợp pháp: học sinh có thể tải và sử dụng mà không tốn phí bản quyền.
  • Đa nền tảng: cùng một file SVG mở được trên nhiều hệ điều hành.
  • Xuất đa định dạng: từ bản vẽ vector có thể xuất ra PNG, JPEG, PDF để chia sẻ, in ấn.

3. Màn hình làm việc của Inkscape

  • Thanh menu: chứa các lệnh File (tệp), Edit (sửa), View (xem), Object (đối tượng), Path (đường), Text (văn bản)...
  • Thanh công cụ (toolbox) bên trái: các công cụ chọn, vẽ hình, vẽ đường, văn bản, tô màu...
  • Vùng vẽ (canvas) ở giữa: hiển thị trang giấy và các đối tượng đồ họa.
  • Thanh màu (palette) phía dưới: bấm để chọn nhanh màu tô, màu viền.
  • Thanh trạng thái dưới cùng: gợi ý thao tác, tọa độ con trỏ, thông tin đối tượng đang chọn.

Phân biệt Save và Export:

  • Save (Ctrl+S): lưu file làm việc định dạng SVG — giữ nguyên mọi đối tượng để mở ra chỉnh sửa tiếp.
  • Export (Ctrl+Shift+E): tạo file thành phẩm (PNG, PDF...) để chia sẻ, in ấn — không chỉnh sửa từng đối tượng được nữa.

Khi xuất PNG có thể chọn vùng xuất (cả trang — Page, cả bản vẽ — Drawing, vùng đang chọn — Selection) và độ phân giải: ảnh xem trên màn hình chỉ cần 72–96 DPI, ảnh in chất lượng cao cần khoảng 300 DPI.

📌 Ghi nhớ

  • Luôn giữ file SVG gốc để chỉnh sửa; xuất thêm PNG/PDF tùy mục đích sử dụng.
  • Lưu thường xuyên (Ctrl+S) trong quá trình vẽ để tránh mất dữ liệu.
  • Đặt tên file gợi nhớ, sắp xếp đối tượng gọn gàng khi bản vẽ phức tạp.

Tóm tắt toàn bài

  • Raster: lưới pixel, phóng to bị vỡ, file nặng — phù hợp ảnh chụp. Vector: đối tượng + công thức, phóng to không vỡ, file nhẹ — phù hợp logo, sơ đồ.
  • Inkscape: phần mềm đồ họa vector miễn phí, mã nguồn mở, đa nền tảng; file gốc định dạng SVG.
  • Màn hình gồm: thanh menu, thanh công cụ (trái), vùng vẽ canvas (giữa), thanh màu palette (dưới), thanh trạng thái.
  • Save lưu file làm việc SVG; Export tạo thành phẩm PNG/PDF; in ấn cần khoảng 300 DPI.
