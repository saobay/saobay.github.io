Bài 26: Hàm trong Python

Chủ đề 5: Giải quyết vấn đề với sự trợ giúp của máy tính

1. Khái niệm hàm

Hàm (function) là một khối lệnh được đặt tên, thực hiện một nhiệm vụ cụ thể và có thể tái sử dụng nhiều lần. Dùng hàm giúp chương trình ngắn gọn, rõ ràng, dễ kiểm thử và gỡ lỗi.

Python có sẵn nhiều hàm như print(), input(), len(), int()... và cho phép người dùng tự định nghĩa hàm mới.

2. Định nghĩa và gọi hàm

Dùng từ khóa def để định nghĩa hàm:

def ten_ham(tham_số_1, tham_số_2, ...):
    khối lệnh trong thân hàm
    return giá_trị_trả_về   # có thể không có
def tong(a, b):
    return a + b

print(tong(4, 5))   # 9
print(tong(10, 20)) # 30

Các khái niệm:

  • Tham số: biến ghi trong ngoặc khi định nghĩa hàm (ví dụ a, b).
  • Đối số: giá trị cụ thể truyền vào khi gọi hàm (ví dụ 4, 5).
  • Giá trị trả về: kết quả hàm đưa ra qua lệnh return.

3. Lệnh return

Lệnh return kết thúc hàm ngay lập tức và trả giá trị về nơi gọi. Hàm không có return (hoặc return không có giá trị) sẽ trả về None.

def la_so_chan(n):
    if n % 2 == 0:
        return True
    return False

print(la_so_chan(8))  # True

Phân biệt:

print() chỉ in ra màn hình, còn return đưa giá trị về để chương trình dùng tiếp. Hàm tính toán nên dùng return.

4. Hàm đệ quy

Hàm đệ quy là hàm gọi lại chính nó. Hàm đệ quy phải có điểm dừng (trường hợp không gọi tiếp), nếu không sẽ lặp vô hạn và gây lỗi khi chạy.

def giai_thua(n):
    if n == 1:       # điểm dừng
        return 1
    return n * giai_thua(n - 1)

print(giai_thua(5))  # 120
